# Project Memory

## Core
Premium enterprise dark UI (Linear/Vercel style): bg #0B1220, cards #1E293B, teal #14B8A6 accent, amber #F59E0B secondary. Never bright colors, pure white or pure black.
18px card radius, soft shadow, thin border, hover lift. Glassmorphism only for login/dialogs. Inter font, Lucide icons, Recharts, Motion animations.
Dark is default theme; theme toggle offers dark/light/system and persists.
